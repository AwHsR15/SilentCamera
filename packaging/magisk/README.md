# SilentCamera Shutter Audio 2.0

Install from Magisk 20.4+ on a booted rooted device and reboot. Only existing allowlisted shutter OGG files in system/vendor/product/system_ext are overlaid. No matching files aborts installation. No original partition file is deleted. Disable or remove the module and reboot to restore. Camera APK resources and HAL sounds may be unaffected; Japanese hardware is unverified.

The asset is a generated 0.2-second mono 44.1kHz silent Vorbis file. Project scripts and the asset are MIT licensed. The installed Magisk runtime is required and not bundled.
